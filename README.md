# Dainik Sangbad (দৈনিক সংবাদ)

Dainik Sangbad is a modern, fast, and fully responsive Bengali online news portal application built with Next.js (App Router) and Tailwind CSS. Designed to deliver authentic, objective, and timely news, the platform features clean typography, live weather, real-time prayer timings, category filtering, and an optimized reading experience across all devices.

## Overview

This platform provides readers with a seamless digital journalism experience. Beyond standard headlines, highlights, and categorized feeds, it incorporates dynamic features like live weather telemetry and prayer schedules. The application automatically filters out third-party social media promotional elements to maintain editorial integrity and readability.

## Features

* **Modern Editorial Layout:** Well-structured homepage featuring top highlights, leading stories, and categorized news grids.
* **Dynamic Article Pages:** Rich article details with high-resolution imagery, photo credits, publication timestamps, and interactive topic tags.
* **Content Filtering:** Advanced filtering algorithms to strip away non-news items, promotional banners, and social channel invites.
* **Live Weather Integration:** Real-time temperature, highs, lows, humidity, and wind speed updates for Dhaka.
* **Dynamic Prayer Schedules:** Automatically updated daily prayer (Salah) times formatted in Bengali digits.
* **Most Read Showcase:** Ranked list of trending stories rendered with localized Bengali numbering.
* **Category Archives & Pagination:** Dedicated category routes (Technology, National, Politics, etc.) with pagination controls.
* **Comprehensive SEO & Meta:** Server-rendered OpenGraph cards, canonical tags, dynamic meta titles, and structured JSON-LD schemas.
* **Skeleton Loading & Error Boundaries:** Smooth skeleton fallbacks and defensive API handling preventing UI crashes on upstream outages.
* **Adaptive Theme & Responsive Design:** Tokenized styling using CSS variables (`--primary`), custom-crafted news cards, and mobile-friendly typography.

## Tech Stack

* **Framework:** Next.js (App Router)
* **Language:** TypeScript / JavaScript
* **Styling:** Tailwind CSS
* **Icons:** React Icons (Feather Icons, Weather Icons, FontAwesome)
* **Deployment:** Vercel
